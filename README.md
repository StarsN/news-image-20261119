A program that writes one image summing up the world news of Thursday 19 November 2026 — the first-ever U.S.–China–Russia trilateral summit in Shenzhen, GTA VI launching worldwide, Anthropic debuting on Nasdaq as ANT, the world court ruling on the Rohingya case, and Jeffries nominated as the first Black speaker-designate — to /output/entry.png. The image was composed for this bounty (a newspaper front page drawn with PIL around an AI-generated globe illustration) and is copied byte-for-byte by main.py; compose.py is the build-time script that drew it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
